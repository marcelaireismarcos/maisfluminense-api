Política de Privacidade

Mais Fluminense
Última atualização: 29 de julho de 2026

Vikkyns North Developer ("nós", "nos" ou "nossos") desenvolvemos o app Mais Fluminense ("App") com um forte compromisso com a sua privacidade e segurança. Esta Política de Privacidade explica como coletamos, usamos, armazenamos e protegemos suas informações.

Ao baixar, instalar ou usar o App, você concorda com as práticas descritas nesta política.

1. Informações que coletamos

1.1. Informações necessárias para o funcionamento do App

  • Leia e atualize o feed de notícias do Fluminense.
  • Categoria Notícias (e.g., Notícias)
→ O App exibe notícias obtidas de fontes públicas RSS (GE, GoogleNews, UOL, 90min) sem armazenar conteúdo em servidores próprios.

1.2. Identificadores de publicidade e dispositivo (Advertising ID)

  • Advertising ID (ID de Publicidade do Google)
  • Informações básicas do dispositivo (modelo, versão do Android, idioma)
→ Utilizado para exibir anúncios relevantes via Google AdMob.
→ Você pode redefinir ou desativar anúncios personalizados em Configurações → Google → Anúncios.

1.3. Notificações push

  • Token de registro do Firebase Cloud Messaging (FCM)
  • Token do OneSignal (identificador único para push)
→ Usado para enviar notificações push com as últimas notícias do Fluminense.
→ Você pode desativar as notificações a qualquer momento em Configurações → Apps → Mais Fluminense → Notificações.

1.4. Dados de uso e diagnóstico (Opcional)

  • Eventos de uso anônimos (telas acessadas, cliques em notícias)
  • Relatórios de falha (crash reports)
→ Enviado via Firebase Analytics e Firebase Crashlytics, sem informações de identificação pessoal.
→ Você pode desativar o analytics em Configurações → Privacidade.
⚠️ Nós NÃO coletamos:
• Localização precisa
• Contatos
• Acesso ao microfone ou câmera
• Dados de saúde sensíveis
• Fotos, vídeos ou arquivos de mídia
• Informações biométricas

2. Anúncios e conteúdo publicitário

2.1. Google AdMob

O App exibe anúncios fornecidos pelo Google AdMob, que podem incluir:

  • Banners — anúncio estático no topo ou rodapé
  • Anúncios Intersticiais — tela cheia entre interações
  • Anúncios Nativos — integrados visualmente ao feed de notícias
  • Anúncios Premiados — vídeo opcional que o usuário pode assistir para remover anúncios por 1 hora
✅ Controle do usuário:
• Você pode assistir a um anúncio premiado para ficar 3 (três) minutos, no mínimo, sem anúncios no App
• Todos os tipos de anúncio (banner, interstitial, nativo) são removidos durante este período

2.2. Como funciona o anúncio premiado (Rewarded Ad)

  • Ao ativar "Assistir anúncio", você assiste a um vídeo curto e opcional.
  • Após concluir, todos os anúncios do App são desativados por 3 (três) minutos.
  • Você pode ativar este recurso quantas vezes desejar.
  • Nenhum dado pessoal é coletado para esta funcionalidade.

3. Assinaturas e conteúdo premium

Atualmente, o Mais Fluminense não oferece assinaturas pagas. Todo o conteúdo do App é gratuito, incluindo:

  • Feed de notícias completo do Fluminense
  • Classificação e jogos (tabela e calendário)
  • Notificações push de últimas notícias

No futuro, caso venhamos a oferecer assinaturas, esta política será atualizada e você será notificado.

4. Serviços de terceiros

Serviço Propósito Dados compartilhados
Google AdMob Exibir anúncios no App Advertising ID, dados de dispositivo
Firebase Analytics Análise anônima de uso do App Eventos de uso (anônimos)
Firebase Crashlytics Diagnosticar falhas do App Relatórios de falha (anônimos)
Firebase Cloud Messaging Enviar notificações push Token FCM
OneSignal Gerenciamento de notificações push e engajamento ID único do OneSignal, dados de interação com notificações
→ Cada serviço possui sua própria política de privacidade. Recomendamos consultá-las para mais detalhes.

5. Conteúdo de notícias e fontes

5.1. Fontes de notícias

O App agrega notícias sobre o Fluminense a partir das seguintes fontes públicas:

  • Gazeta Esportiva — Feed RSS direto
  • Explosao Tricolor (explosaotricolor.com.br) — Feed RSS direto
  • UOL Esporte — via Google News
  • 90min — via Google News
→ O App apenas exibe o conteúdo das fontes originais.
→ Não armazenamos, modificamos ou republicamos o conteúdo em servidores próprios.
→ Todo o crédito do conteúdo pertence às fontes originais.

5.2. Links externos

Ao clicar em uma notícia, você será direcionado ao site da fonte original. Recomendamos ler as políticas de privacidade de cada site que você visitar, pois não temos controle sobre o conteúdo ou práticas de terceiros.

5.3. Imagens das notícias

As imagens exibidas no feed são carregadas diretamente das fontes originais via metadados Open Graph (og:image). O App não hospeda, armazena ou distribui estas imagens.

6. Armazenamento de dados no dispositivo

6.1. Cache e dados locais

  • Cache de notícias: O App armazena localmente as notícias carregadas para funcionamento offline parcial.
  • Preferências do usuário: Configurações como tema escuro/claro, preferências de anúncios e visualizações são salvas via SharedPreferences.
  • Cache de imagens: Imagens de notícias são armazenadas em cache para carregamento mais rápido.
→ Todos os dados ficam apenas no seu dispositivo.
→ Você pode limpar o cache a qualquer momento em Configurações → Apps → Mais Fluminense → Armazenamento → Limpar cache.

6.2. Dados de conectividade

  • O App verifica periodicamente a conexão com a internet usando ConnectivityReceiver e InternetMonitor.
  • Esta verificação é feita localmente e não envia dados para servidores externos.

7. Segurança e seus direitos

7.1. Medidas de segurança

  • Comunicação via HTTPS para todas as requisições de rede
  • Não há armazenamento em nuvem de dados pessoais
  • Uso de Network Security Configuration do Android para proteção contra interceptação
  • Princípio de minimização de dados — coletamos apenas o necessário para o funcionamento

7.2. Seus Direitos (LGPD/GDPR/CCPA)

Você pode, a qualquer momento:

  • ✅ Acessar informações sobre quais dados coletamos
  • ✅ Solicitar a exclusão dos dados armazenados (via limpeza de dados do App)
  • ✅ Retirar o consentimento — desative anúncios personalizados ou desinstale o App
  • ✅ Desativar notificações push nas configurações do dispositivo
  • ✅ Redefinir seu Advertising ID em Configurações → Google → Anúncios → Redefinir ID de publicidade

Para exercer esses direitos, envie-nos um e-mail para:
📧 vikkynsnorth@gmail.com
Responderemos em até 15 dias úteis.

8. Cookies e tecnologias semelhantes

O App não utiliza cookies.
Utiliza apenas armazenamento local no dispositivo:

  • SharedPreferences: para configurações locais (tema escuro/claro, preferências de anúncios)
  • Banco de dados local (SQLite/Room): para cache de notícias e dados de classificação/jogos
  • Cache de imagens: para carregamento eficiente de fotos de notícias

Os serviços de terceiros (AdMob, Firebase) podem usar cookies em seus respectivos websites, mas o App em si não os utiliza diretamente.

9. Crianças

Nosso App não é direcionado a crianças menores de 13 anos. Não coletamos intencionalmente dados pessoais de crianças. Se você acredita que isso ocorreu, entre em contato para que possamos remover os dados imediatamente.

O uso do Google AdMob neste App segue as políticas de conteúdo adequado para todas as idades, e anúncios personalizados são exibidos conforme as preferências de consentimento do usuário.

10. Transferências internacionais de dados

Seus dados não saem do Brasil, exceto:

  • Google AdMob (EUA): para exibição de anúncios
  • Firebase (EUA): para análises anônimas, diagnóstico de falhas e notificações push
  • OneSignal (EUA): para gerenciamento de notificações push

Todos estão em conformidade com o EU-U.S. Data Privacy Framework, GDPR e LGPD.
